# dsh-playmate 纠错词表示例
#
# 语音识别对专有名词、英文缩写和同音字一向不稳。这个文件是给你的补救入口。
#
# 用法：把本文件复制一份、按需修改，然后在设置里把「纠错词表」指过去。
#      不填就完全不启用，识别行为和原来一模一样。
#
# 每行一条规则，三种写法：
#
#   错 => 对          显式替换。你确定它会错成这个样子时用。
#   => 正确词         纯热词。不去猜它会错成什么样，交给拼音模糊匹配去抓近音写法。
#   re:模式 => 替换   带上下文的正则。想限制「只在某种前后文里才替换」时用。
#
# 以 # 开头是注释，空行忽略。
# 改文件内容不用重启引擎——每次识别前都会重读；改的是路径才需要重启。

# ---- 显式替换 ----
# 英文缩写常被识别成一串同音汉字，这种直接写死最省事
深度求索 => DeepSeek

# ---- 纯热词 ----
# 只希望这个词更容易被认对，不指定它会错成什么样
=> 人工智能

# ---- 正则 ----
# 只在一串数字后面，才把「块」当成「元」
re:(\d+)\s*块 => \1元
